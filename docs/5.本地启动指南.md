# 本地启动指南

## 前置条件

| 工具 | 版本要求 |
|------|----------|
| JDK | 17+ |
| Maven | 3.8+ |
| Node.js | 18+（本机已有） |
| MySQL | 8.0+，或直接使用远程库 |

---

## 第一步：初始化数据库

远程库连接信息（`dev.config`）：

```
Host:     39.105.212.130:3306
Database: dev_db
Username: root
Password: DevRoot@2026
```

需要按顺序执行项目中的三个 SQL 文件：

```
ai-studio-service/src/main/resources/db/V1__init_sys_tables.sql   # 系统表（用户、角色、菜单）
ai-studio-service/src/main/resources/db/V2__init_biz_tables.sql   # 业务表（skill、mcp、plugin 等）
ai-studio-service/src/main/resources/db/V3__init_data.sql         # 初始数据（角色、菜单、admin账号）
```

### 方式一：使用 Navicat（推荐）

1. 打开 Navicat，新建连接：
   - 主机：`39.105.212.130`，端口：`3306`
   - 用户名：`root`，密码：`DevRoot@2026`
2. 连接成功后，双击打开 `dev_db` 数据库
3. 点击顶部菜单 **查询 → 新建查询**
4. 点击左上角 **打开文件**，选择 `V1__init_sys_tables.sql`，点击 **运行**
5. 重复步骤 4，依次执行 `V2__init_biz_tables.sql`、`V3__init_data.sql`

### 方式二：使用 DBeaver

1. 新建连接 → MySQL，填入上方连接信息
2. 左侧展开 `dev_db` 数据库，右键 → **SQL 编辑器 → 新建 SQL 编辑器**
3. 复制粘贴3个 SQL 文件后点击 **执行脚本（Ctrl+Alt+X）**
4. 按顺序执行三个文件

### 方式三：命令行

在项目根目录下执行（需本机安装 MySQL 客户端）：

```bash
mysql -h 39.105.212.130 -P 3306 -u root -pDevRoot@2026 dev_db < ai-studio-service/src/main/resources/db/V1__init_sys_tables.sql
mysql -h 39.105.212.130 -P 3306 -u root -pDevRoot@2026 dev_db < ai-studio-service/src/main/resources/db/V2__init_biz_tables.sql
mysql -h 39.105.212.130 -P 3306 -u root -pDevRoot@2026 dev_db < ai-studio-service/src/main/resources/db/V3__init_data.sql
```

> 三个文件必须按顺序执行，V3 依赖 V1/V2 的表结构。已初始化过则跳过此步骤。

## 第二步：配置七牛云 Domain

打开 `ai-studio-service/src/main/resources/application.yml`，将 domain 替换为实际域名：

```yaml
qiniu:
  domain: http://qiniu.tenmagabrielwhite.cn
  bucket: topazzz   # 确认与实际 bucket 名一致
```

> 使用自定义源站域名无需加速域名，直接填写即可。如果域名已绑定 HTTPS 证书，将 `http://` 改为 `https://`。

---

## 第三步：启动后端

```bash
cd ai-studio-service
mvn spring-boot:run
```

或用 IntelliJ IDEA 打开 `ai-studio-service/` 目录，直接运行 `AiStudioApplication.java`。

启动成功后：
- 服务端口：`http://localhost:8080`
- API 文档（Knife4j）：`http://localhost:8080/doc.html`

---

## 第四步：启动前端

```bash
cd ai-studio-web
npm install
npm run dev
```

启动成功后：
- 前端地址：`http://localhost:5173`
- `/api` 请求自动代理到 `localhost:8080`
