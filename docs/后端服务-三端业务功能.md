# AI-Studio 后端服务 - 三端业务功能梳理

## 1. 三端架构概述

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         AI-Studio 后端服务                              │
│                    (Spring Boot 3.2.5 + MyBatis Plus)                  │
├─────────────────────┬─────────────────────┬─────────────────────────────┤
│   Portal 门户端      │   Console 控制台端   │      Admin 管理端           │
│   (普通用户)         │   (注册用户/创作者)   │    (管理员/超级管理员)      │
├─────────────────────┼─────────────────────┼─────────────────────────────┤
│ · 资源浏览(公开)     │ · 资源管理(上传/发布) │ · 系统管理                  │
│ · 社区互动           │ · 个人产出记录        │ · 资源审核/下架            │
│ · 收藏/浏览历史      │ · 我的资源列表        │ · 用户/角色/权限管理        │
│ · 通知中心           │ · 版本管理            │ · 数据统计看板              │
│ · 个人信息           │                      │ · 产出统计                  │
└─────────────────────┴─────────────────────┴─────────────────────────────┘
```

### 路由前缀与认证要求

| 端 | 路由前缀 | 认证要求 | 主要角色 |
|----|---------|---------|---------|
| 公共 | `/auth/*` | 无需认证 | - |
| Portal | `/portal/*` | 部分需认证 | 访客、注册用户 |
| Portal | `/api/*` | 需认证 | 注册用户 |
| Console | `/console/*` | 需认证 | USER |
| Admin | `/admin/*` | 需认证 | SUPER_ADMIN, OP_ADMIN, DEPT_ADMIN |

## 8. 关键业务规则汇总

### 8.1 资源发布流程

```
用户(创作者)              Console                   Admin
    │                       │                        │
    │──上传文件────────────►│                        │
    │                       │──提交审核─────────────►│
    │                       │                        │──审核通过
    │                       │                        │──发布上线
    │◄──资源可下载──────────│                        │
```

### 8.2 社区内容生命周期

```
创建 ──► 发布 ──► (用户互动: 点赞/评论/收藏) ──► (管理员)下架/删除
 │         │                                            │
 └─────────┴────────────────────────────────────────────┘
                    逻辑删除
```

### 8.3 问答采纳流程

```
用户A 提问 ──► 用户B/C/D 回答 ──► 用户A 采纳最佳答案 ──► 问题关闭
                   │
                   └── 被采纳的回答 is_best=1，排序置顶
```
