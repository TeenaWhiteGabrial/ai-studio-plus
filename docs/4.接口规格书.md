## 第二章：统一规范

### 2.1 请求头规范

所有需要认证的接口，均须在请求头中携带 JWT Token：

```
Authorization: Bearer <token>
Content-Type: application/json
```

文件上传接口使用：

```
Authorization: Bearer <token>
Content-Type: multipart/form-data
```

### 2.2 统一响应格式

所有接口均返回统一的响应结构：

```typescript
interface ApiResponse<T = any> {
  code: number;      // 0 表示成功，非 0 表示失败
  data: T;           // 业务数据，失败时可为 null
  message: string;   // 提示信息，成功时为 "success" 或具体说明
}
```

**分页响应数据结构：**

```typescript
interface PageResult<T> {
  list: T[];         // 当前页数据列表
  total: number;     // 总记录数
  page: number;      // 当前页码
  size: number;      // 每页条数
  pages: number;     // 总页数
}
```

**响应示例（成功）：**

```json
{
  "code": 0,
  "data": { ... },
  "message": "success"
}
```

**响应示例（失败）：**

```json
{
  "code": 40300,
  "data": null,
  "message": "无权限操作该资源"
}
```

### 2.3 分页请求参数规范

所有列表查询接口均支持以下通用分页参数（Query String）：

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `page` | number | 1 | 页码，从 1 开始 |
| `size` | number | 10 | 每页条数，最大 100 |
| `keyword` | string | — | 关键词搜索（模糊匹配标题/名称） |
| `sortField` | string | `created_at` | 排序字段 |
| `sortOrder` | string | `desc` | 排序方向：`asc` / `desc` |

### 2.4 错误码定义

| HTTP 状态码 | 业务 code | 说明 |
|------------|-----------|------|
| 200 | 0 | 请求成功 |
| 400 | 40000 | 请求参数错误（通用） |
| 400 | 40001 | 参数缺失或格式不合法 |
| 400 | 40002 | 业务校验失败（如日期不合法） |
| 401 | 40100 | 未登录或 Token 失效，需重新登录 |
| 401 | 40101 | Token 已过期 |
| 403 | 40300 | 无权限访问该资源 |
| 403 | 40301 | 无权限操作他人资源 |
| 404 | 40400 | 资源不存在 |
| 500 | 50000 | 服务器内部错误 |
| 500 | 50001 | 第三方服务异常（如七牛云） |

### API-08：批量导入 Skill（ZIP上传）

| 配置项 | 值 |
|-------|-----|
| 方法 | POST |
| 路径 | `/api/skill/import` |
| 认证 | 必需 |
| 权限 | USER 及以上 |
| Content-Type | multipart/form-data |

> ZIP 包内须包含各 Skill 子目录，每个子目录含 `meta.json`（描述信息）和实际文件。后端解压后逐条入库，`created_by` 设为当前登录用户。

#### 请求体（Form Data）

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `file` | File | 是 | ZIP 格式压缩包，最大 100MB |

**ZIP 包内 meta.json 格式示例：**

```json
{
  "title": "Skill 名称",
  "description": "描述信息",
  "category": "分类",
  "tags": ["标签1", "标签2"]
}
```

#### 响应体

```typescript
interface ImportSkillResponse {
  code: 0;
  data: {
    totalCount: number;     // ZIP 包内总条目数
    successCount: number;   // 成功导入条数
    failCount: number;      // 失败条数
    failDetails: Array<{
      name: string;         // 条目名称
      reason: string;       // 失败原因
    }>;
  };
  message: string;
}
```

#### 错误响应

| code | 说明 |
|------|------|
| 40001 | 文件格式不合法或 ZIP 包结构不正确 |
| 40100 | 未登录 |
| 50000 | 服务器解压/入库异常 |

### API-43：获取七牛云 UpToken

| 配置项 | 值 |
|-------|-----|
| 方法 | POST |
| 路径 | `/api/upload/token` |
| 认证 | 必需 |
| 权限 | USER 及以上 |

> 前端在上传文件前，先调用此接口获取七牛云上传凭证（UpToken），然后由前端直接向七牛云上传文件（客户端直传模式），上传完成后将七牛云返回的 `key` 传给业务接口（如创建 Skill 时的 `fileKey` 字段）。
> Token 有效期建议 1 小时，前端应在 Token 过期前重新获取。

#### 请求体

```typescript
interface GetUpTokenRequest {
  fileType: 'skill' | 'plugin' | 'tutorial_cover' | 'avatar';  // 必填，文件业务类型，决定存储目录前缀
  fileName: string;   // 必填，原始文件名（用于生成唯一 key，后端拼接 UUID）
}
```

#### 响应体

```typescript
interface GetUpTokenResponse {
  code: 0;
  data: {
    token: string;      // 七牛云 UpToken（上传凭证）
    key: string;        // 文件存储 key（后端生成，格式：{keyPrefix}{uuid}_{fileName}）
    domain: string;     // CDN 访问域名，如 "https://cdn.example.com"
    keyPrefix: string;  // 文件 key 前缀，如 "skill/"、"plugin/"
    expireAt: number;   // Token 过期时间戳（Unix 秒）
  };
  message: string;
}
```

**文件 key 前缀规则：**

| fileType | keyPrefix |
|----------|-----------|
| `skill` | `skill/` |
| `plugin` | `plugin/` |
| `tutorial_cover` | `tutorial/cover/` |
| `avatar` | `user/avatar/` |

#### 错误响应

| code | 说明 |
|------|------|
| 40001 | 参数缺失或 fileType 不合法 |
| 40100 | 未登录 |
| 50001 | 七牛云 UpToken 生成失败 |

```
前端                         后端                      七牛云
 |                             |                          |
 |--- POST /api/upload/token ->|                          |
 |                             |--- 生成 UpToken -------->|
 |                             |<-- 返回 UpToken ----------|

 |                             |                          |
```
