# AI Coding 管理端 - 产品需求规格说明书

## 1. 项目概述

### 1.1 项目定位
面向平台管理员的管理后台，提供用户管理、内容审核、数据报表、运营配置等功能。

### 1.2 目标用户

| 角色 | 说明 | 权限 |
|------|------|------|
| 超级管理员 | 最高权限 | 所有功能 |
| 运营管理员 | 日常运营 | 资源管理、审核、报表 |
| 审核员 | 内容审核 | 仅审核相关功能 |

### 1.3 核心目标
- 高效管理平台用户和团队
- 审核用户上传的内容，确保质量
- 查看平台数据，了解运营情况
- 配置首页运营内容，提升用户体验

## 3. 非功能性需求

| 类别 | 要求 |
|------|------|
| 性能 | 页面加载 < 1s，大数据量分页 < 2s |
| 体验 | 操作有确认提示，批量操作有进度反馈 |
| 安全 | 敏感操作需二次确认，操作日志完整记录 |
| 响应式 | 适配桌面端，最小宽度 1280px |

## 5. 界面风格

- **布局**: 左侧固定菜单(200px) + 右侧主内容区
- **菜单**: 深色背景 #304156，选中高亮 #409eff
- **主内容**: 浅灰背景 #f5f7fa
- **卡片**: 白色背景，圆角，阴影
- **表格**: 斑马纹，hover效果，固定表头
- **按钮**: 主要操作用 primary，危险操作用 danger
- **标签**: 状态用 Tag 组件，不同状态不同颜色
