## 3. 数据库初始化

### 3.1 创建数据库

```sql
-- 连接 MySQL
mysql -u root -p

-- 创建数据库（生产环境建议使用独立数据库名）
CREATE DATABASE ai_studio CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建专用数据库用户（生产环境请使用强密码）
CREATE USER 'ai_studio_user'@'localhost' IDENTIFIED BY 'your_strong_password';
GRANT ALL PRIVILEGES ON ai_studio.* TO 'ai_studio_user'@'localhost';
FLUSH PRIVILEGES;
```

### 3.2 执行初始化脚本

数据库脚本位于 `ai-studio-service/src/main/resources/db/`，按顺序执行：

```bash
# 进入项目目录
cd /path/to/ai-studio

# 执行系统表初始化
mysql -u ai_studio_user -p ai_studio < ai-studio-service/src/main/resources/db/V1__init_sys_tables.sql

# 执行业务表初始化
mysql -u ai_studio_user -p ai_studio < ai-studio-service/src/main/resources/db/V2__init_biz_tables.sql

# 执行初始数据导入
mysql -u ai_studio_user -p ai_studio < ai-studio-service/src/main/resources/db/V3__init_data.sql
```

### 3.3 验证数据库

```sql
USE ai_studio;
SHOW TABLES;
-- 预期显示系统表和业务表列表

-- 验证初始管理员账号
SELECT username, status FROM sys_user WHERE username = 'admin';
```

## 4. 后端服务部署

### 4.1 获取源码

```bash
git clone <repository-url> /opt/ai-studio
cd /opt/ai-studio
```

### 4.2 修改生产环境配置

编辑 `ai-studio-service/src/main/resources/application.yml`，将以下配置替换为生产环境值：

```yaml
server:
  port: 8080

spring:
  application:
    name: ai-studio-service
  datasource:
    url: jdbc:mysql://<生产数据库主机>:3306/ai_studio?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: ai_studio_user
    password: <数据库密码>
    driver-class-name: com.mysql.cj.jdbc.Driver
  jackson:
    date-format: yyyy-MM-dd HH:mm:ss
    time-zone: Asia/Shanghai

mybatis-plus:
  mapper-locations: classpath:mapper/*.xml
  type-aliases-package: com.aistudio.service.entity
  global-config:
    db-config:
      logic-delete-field: deleted
      logic-delete-value: 1

# JWT 配置（生产环境请使用强密钥，至少 256 位）
jwt:
  secret: <生产环境强密钥>
  expiration: 86400000

# 七牛云配置
qiniu:
  access-key: <七牛云 AccessKey>
  secret-key: <七牛云 SecretKey>
  bucket: <存储空间名称>
  domain: <七牛云访问域名>
  token-expire: 3600

# RSA 密钥对（生产环境请重新生成）
rsa:
  private-key: <RSA 私钥>
  public-key: <RSA 公钥>
```

> **安全提示：** 生产环境建议将敏感配置（数据库密码、JWT 密钥、七牛云密钥等）通过环境变量或 Secret 管理服务注入，避免硬编码在配置文件中。

**使用环境变量注入示例：**

```yaml
spring:
  datasource:
    password: ${DB_PASSWORD}

jwt:
  secret: ${JWT_SECRET}

qiniu:
  access-key: ${QINIU_ACCESS_KEY}
  secret-key: ${QINIU_SECRET_KEY}
```

### 4.3 构建 JAR 包

```bash
cd /opt/ai-studio/ai-studio-service

# 跳过测试打包（生产部署推荐）
mvn clean package -DskipTests

# 构建产物位于
ls target/ai-studio-service-*.jar
```

### 4.4 创建系统服务（systemd）

创建 `/etc/systemd/system/ai-studio.service`：

```ini
[Unit]
Description=AI Studio Backend Service
After=network.target mysql.service

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/ai-studio/ai-studio-service

# 生产环境通过环境变量注入敏感配置
Environment="DB_PASSWORD=your_db_password"
Environment="JWT_SECRET=your_jwt_secret"
Environment="QINIU_ACCESS_KEY=your_access_key"
Environment="QINIU_SECRET_KEY=your_secret_key"

ExecStart=/usr/bin/java \
  -Xms512m \
  -Xmx1024m \
  -jar /opt/ai-studio/ai-studio-service/target/ai-studio-service-*.jar \
  --spring.profiles.active=prod

Restart=on-failure
RestartSec=10
StandardOutput=journal
StandardError=journal
SyslogIdentifier=ai-studio

[Install]
WantedBy=multi-user.target
```

### 4.5 启动服务

```bash
# 重新加载 systemd 配置
sudo systemctl daemon-reload

# 启用开机自启
sudo systemctl enable ai-studio

# 启动服务
sudo systemctl start ai-studio

# 查看服务状态
sudo systemctl status ai-studio

# 查看实时日志
sudo journalctl -u ai-studio -f
```

### 4.6 验证后端服务

```bash

curl http://localhost:8080/actuator/health
# 预期响应：{"status":"UP"}
```

## 6. Nginx 反向代理配置

### 6.1 创建 Nginx 站点配置

创建 `/etc/nginx/conf.d/ai-studio.conf`：

```nginx
server {
    listen 80;
    server_name your-domain.com;  # 替换为实际域名或服务器 IP

    # 前端静态文件
    location / {
        root /var/www/ai-studio;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:8080/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_connect_timeout 60s;
        proxy_read_timeout 60s;
        # 文件上传大小限制（与后端保持一致）
        client_max_body_size 110m;
    }

    # 日志配置
    access_log /var/log/nginx/ai-studio-access.log;
    error_log  /var/log/nginx/ai-studio-error.log;
}
```

### 6.2 启用 HTTPS（推荐）

使用 Certbot 申请免费 SSL 证书：

```bash
# 安装 Certbot
sudo apt install -y certbot python3-certbot-nginx

# 申请证书（自动修改 Nginx 配置）
sudo certbot --nginx -d your-domain.com

# 验证自动续期
sudo certbot renew --dry-run
```

### 6.3 检查并重载 Nginx

```bash
# 检查配置语法
sudo nginx -t

# 重载配置（不中断服务）
sudo systemctl reload nginx

# 查看 Nginx 状态
sudo systemctl status nginx
```

## 7. 七牛云对象存储配置

七牛云用于存储用户上传的文件（图片、附件等）。

### 7.1 获取配置信息

登录[七牛云控制台](https://portal.qiniu.com)，获取以下信息：

| 配置项 | 说明 | 获取路径 |
|--------|------|----------|
| `access-key` | AccessKey | 个人中心 → 密钥管理 |
| `secret-key` | SecretKey | 个人中心 → 密钥管理 |
| `bucket` | 存储空间名称 | 对象存储 → 空间管理 |
| `domain` | 访问域名 | 空间概览 → 域名信息 |

### 7.2 存储空间设置

1. 进入七牛云控制台 → 对象存储
2. 创建存储空间，选择合适的存储区域
3. 设置存储空间访问控制（建议**公开读、私有写**）
4. 绑定自定义域名（推荐，提升访问速度）

### 7.3 跨域配置

在七牛云控制台配置跨域规则，允许前端域名访问：

```
Origin: https://your-domain.com
Method: GET, POST, HEAD
Headers: *
```

## 9. 常见问题排查

### 9.1 后端服务启动失败

**症状：** `systemctl status ai-studio` 显示 `failed`

**排查步骤：**

```bash
# 查看详细错误日志
sudo journalctl -u ai-studio -n 100 --no-pager

# 常见问题：
# 1. 数据库连接失败
#    → 检查 application.yml 中数据库配置
#    → 验证数据库服务是否启动：systemctl status mysql
#    → 检查防火墙是否放行 3306 端口

# 2. 端口被占用
#    → 查看占用 8080 端口的进程：lsof -i :8080
#    → 终止冲突进程或修改服务端口

# 3. JAR 包不存在
#    → 重新构建：cd /opt/ai-studio/ai-studio-service && mvn clean package -DskipTests
```

### 9.2 前端页面空白

**症状：** 访问页面显示空白或 404

**排查步骤：**

```bash
# 检查静态文件是否存在
ls /var/www/ai-studio/

# 检查 Nginx 错误日志
sudo tail -f /var/log/nginx/ai-studio-error.log

# 检查文件权限
ls -la /var/www/ai-studio/index.html
# 应为 www-data 用户可读

# 重新检查 Nginx 配置
sudo nginx -t
```

### 9.3 API 请求失败（502/504）

**症状：** 前端请求接口返回 502 Bad Gateway 或 504 Gateway Timeout

**排查步骤：**

```bash
# 确认后端服务是否正常运行
curl http://localhost:8080/actuator/health

# 检查 Nginx 代理配置
# 确认 proxy_pass 地址与后端端口一致

# 查看 Nginx 访问日志
sudo tail -f /var/log/nginx/ai-studio-access.log
```

### 9.4 文件上传失败

**症状：** 文件上传时报错或七牛云 Token 获取失败

**排查步骤：**

1. 检查 `application.yml` 中七牛云配置是否正确
2. 验证 AccessKey/SecretKey 有效性（登录七牛云控制台确认）
3. 检查存储空间名称和所在区域是否匹配
4. 确认七牛云域名配置正确且已备案（国内服务器要求）
5. 检查 Nginx `client_max_body_size` 是否满足文件大小需求

### 9.5 登录失败

**症状：** 输入正确账号密码后登录失败

**排查步骤：**

```bash
# 检查数据库中初始数据是否导入
mysql -u ai_studio_user -p ai_studio -e "SELECT username, status FROM sys_user;"

# 检查后端日志中的登录错误
sudo journalctl -u ai-studio -f | grep -i "login\|auth\|password"

# 前端 RSA 公钥是否与后端私钥匹配
# → 确认 application.yml 中 rsa.public-key 和 rsa.private-key 为同一密钥对
```

### 9.6 日志位置汇总

| 服务 | 日志位置 |
|------|----------|
| 后端服务 | `journalctl -u ai-studio` |
| Nginx 访问日志 | `/var/log/nginx/ai-studio-access.log` |
| Nginx 错误日志 | `/var/log/nginx/ai-studio-error.log` |
| MySQL 错误日志 | `/var/log/mysql/error.log` |
