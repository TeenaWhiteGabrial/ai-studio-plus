# AI Studio 平台 - 数据模型设计书

## 1. 实体关系图 (ERD)

```
┌─────────────┐       ┌──────────────────┐       ┌─────────────┐
│   sys_user  │ 1   N │  sys_user_role   │ N   1 │  sys_role   │
│             │───────│                  │───────│             │
└─────────────┘       └──────────────────┘       └─────────────┘
       │                                                 │
       │ 1                                             1 │
       │                                                 │
       │           ┌──────────────────┐                 │
       │           │  sys_role_menu   │ N   1  ┌────────┴────┐
       │           │                  │────────│  sys_menu   │
       │           └──────────────────┘        └─────────────┘
       │
       │ 1
       ├──────────── N ──────────────┐
       │                             │
┌──────┴──────┐               ┌─────┴────────┐
│    skill    │               │  mcp_server  │
└─────────────┘               └──────────────┘
       │ created_by                  │ created_by
       │
┌──────┴──────┐               ┌─────┴────────┐
│   plugin    │               │   tutorial   │
└─────────────┘               └──────────────┘
       │ created_by                  │ created_by
       │
┌──────┴──────────┐
│  member_output  │ N ───── 1  sys_user (user_id)
└─────────────────┘
```

**关系说明**：
- `sys_user` 与 `sys_role` 多对多，通过 `sys_user_role` 中间表关联
- `sys_role` 与 `sys_menu` 多对多，通过 `sys_role_menu` 中间表关联
- `skill`、`mcp_server`、`plugin`、`tutorial`、`member_output` 均通过 `created_by` / `user_id` 关联 `sys_user`

## 3. 数据表详细定义

### 3.1 表：`skill`

**对应实体**：E01 技能

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
|-------|------|------|--------|------|
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | - | 主键，自增 |
| name | VARCHAR(100) | NOT NULL, UNIQUE | - | Skill 名称（全局唯一） |
| description | VARCHAR(500) | NULL | NULL | 描述 |
| category | VARCHAR(50) | NULL | NULL | 分类，如"前端开发" |
| source | VARCHAR(200) | NULL | NULL | 来源，如"官方" |
| content_oss_key | VARCHAR(500) | NULL | NULL | SKILL.md 文件七牛云 Key |
| content_url | VARCHAR(500) | NULL | NULL | SKILL.md 文件访问 URL |
| status | TINYINT | NOT NULL | 1 | 状态：1-正常，0-禁用 |
| download_count | INT | NOT NULL | 0 | 下载次数 |
| created_by | BIGINT | NOT NULL | - | 创建人 ID（关联 sys_user.id） |
| created_at | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL | CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**索引设计**：

| 索引名 | 字段 | 类型 | 说明 |
|-------|------|------|------|
| uk_name | name | UNIQUE | 名称唯一约束 |
| idx_category | category | BTREE | 分类筛选 |
| idx_status | status | BTREE | 状态筛选 |
| idx_created_by | created_by | BTREE | 按创建人查询（所有权校验） |
| idx_created_at | created_at | BTREE | 时间排序 |

**外键关系**：

| 字段 | 引用表 | 引用字段 | 删除策略 |
|------|-------|---------|---------|
| created_by | sys_user | id | RESTRICT |

## 4. 数据字典

### 枚举值定义

**枚举名：`resource_status`**（适用于 skill、mcp_server、plugin、tutorial 的 status 字段）

| 值 | 说明 |
|----|------|
| 1 | 正常（可见可用） |
| 0 | 禁用（隐藏或不可用） |

**枚举名：`user_status`**（适用于 sys_user.status）

| 值 | 说明 |
|----|------|
| 1 | 正常（可登录） |
| 0 | 禁用（禁止登录） |

**枚举名：`mcp_auth_type`**（适用于 mcp_server.auth_type）

| 值 | 说明 |
|----|------|
| Bearer | Bearer Token 认证 |
| ApiKey | API Key 认证 |
| None | 无需认证 |

**枚举名：`plugin_type`**（适用于 plugin.type）

| 值 | 说明 |
|----|------|
| editor | 编辑器插件 |
| build | 构建工具插件 |
| lint | 代码检查插件 |

**枚举名：`role_code`**（适用于 sys_role.role_code）

| 值 | 说明 |
|----|------|
| SUPER_ADMIN | 超级管理员，拥有全部权限 |
| ADMIN | 普通管理员，管理资源内容 |
| USER | 普通用户，浏览和新增资源、录入产出 |
