# 产出统计字段

| 指标名称 | 数据库字段 | 说明 |
|----------|------------|------|
| PRD 文档数 | prd_doc_count | 产品需求文档数量 |
| 数据模型文档数 | data_model_doc_count | 数据库设计文档数量 |
| API 接口文档数 | api_doc_count | 接口文档数量 |
| Java 文件数 | java_file_count | Java 源文件数量 |
| Java 代码行数 | java_code_lines | Java 有效代码行数（不含空行） |
| API 接口数 | api_count | 控制器方法数量（@RequestMapping 等） |
| 核心业务服务数 | core_biz_service_count | 核心业务服务类数量（@Service） |
| 前端组件数 | frontend_component_count | React/Vue 组件总数 |
| 前端页面数 | frontend_page_count | 页面级组件数量 |
| 前端公共组件数 | frontend_common_component_count | React/Vue 公共组件总数 |
| TypeScript 代码行数 | ts_code_lines | TypeScript 代码行数 |
| 前端代码行数 | frontend_code_lines | 前端有效代码行数（不含空行） |
| 数据库实体数 | entity_count | JPA 实体类数量（@Entity） |
| SQL 脚本数 | sql_script_count | SQL 脚本文件数量 |
| 测试文件数 | test_file_count | 测试文件数量（*Test.java） |
| 总代码行数 | total_code_lines | 所有代码行数汇总 |
