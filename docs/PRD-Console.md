# AI Coding 控制台 - 产品需求规格说明书

## 1. 项目概述

### 1.1 项目定位
面向通过团队认证的用户，提供个人数据管理、API Key 获取、每日任务录入、项目管理及 AI 产出统计等工作台。

### 1.2 目标用户

| 角色 | 说明 |
|------|------|
| 控制台用户 | 已通过团队认证的企业用户 |

### 1.3 核心目标
- 提供便捷的 API Key 管理
- 记录和统计个人工作数据（任务、项目、产出）
- 管理个人上传的资源和收藏
- 统计个人 AI 产出效能（代码行数、文档数）

### 1.4 多人协作说明
- **项目管理**: 任何人可创建项目，所有人可见并可录入任务
- **一人多项目**: 一个用户可同时参与多个项目

#### 2.2 工时任务比指标定义

```
指标 A: 每工时完成任务数
  = 已完成任务数 / 总投入工时
  越高越好

指标 B: 每任务平均工时
  = 总投入工时 / 已完成任务数
  越低越好

统计口径:
  - 范围: 本周 / 本月 (Tab 切换)
  - 只统计"已完成"状态的任务
  - AI 参与度不影响工时计算
```

| 75% | AI 主导，人工审核和调整 |
| 100% | 纯 AI 生成，人工确认 |
