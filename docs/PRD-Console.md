# AI Coding 控制台 - 产品需求规格说明书

## 1. 项目概述

### 1.1 项目定位
面向通过团队认证的用户，提供个人数据管理、API Key 获取、每日任务录入等功能的工作台。

### 1.2 目标用户

| 角色 | 说明 |
|------|------|
| 控制台用户 | 已通过团队认证的企业用户 |

### 1.3 核心目标
- 提供便捷的 API Key 管理
- 记录和统计个人工作数据
- 管理个人上传的资源和收藏

---

## 2. 功能模块

### 模块 M02：API Key 管理

| 配置项 | 值 |
|--------|-----|
| 模块代码 | `console_apikey` |
| 优先级 | P0 |
| 备注 | 每个人只有一个Key，支持查看、复制、刷新 |

#### 2.1 功能点

| 功能 ID | 功能名称 | 用户故事 | 验收标准 |
|---------|---------|---------|---------|
| M02-F01 | 查看 API Key | 作为用户，我希望查看我的 API Key，以便使用 AI Coding | 显示脱敏后的 Key |
| M02-F02 | 复制 API Key | 作为用户，我希望一键复制 Key，以便粘贴到 IDE | 点击复制按钮，复制到剪贴板 |
| M02-F03 | 刷新 API Key | 作为用户，我希望刷新 Key，以便密钥泄露时更换 | 生成新 Key，旧 Key 立即失效 |
| M02-F04 | 使用说明 | 作为用户，我希望看到使用说明，以便正确使用 Key | 展示配置方法和注意事项 |

#### 2.2 页面原型

```
+----------------------------------------------------------+
|                                                          |
|  API Key 管理                                            |
|                                                          |
|  +--------------------------------------------------+   |
|  |                                                  |   |
|  |  我的 API Key                                    |   |
|  |                                                  |   |
|  |  sk-abc...xyz********************************** |   |
|  |                                                  |   |
|  |  [显示] [复制] [刷新 Key]                        |   |
|  |                                                  |   |
|  +--------------------------------------------------+   |
|                                                          |
|  使用说明                                                |
|  1. 点击"复制"按钮复制 API Key                        |
|  2. 在 IDE 或工具的 API Key 配置中粘贴                |
|  3. 如遇 Key 泄露，请立即刷新                         |
|                                                          |
|  注意事项                                                |
|  - Key 是您访问 AI Coding 服务的凭证，请妥善保管      |
|  - 刷新 Key 后旧 Key 将立即失效                       |
|                                                          |
+----------------------------------------------------------+
```

## 3. 非功能性需求

| 类别 | 要求 |
|------|------|
| 性能 | 页面切换 < 500ms，数据加载 < 1s |
| 体验 | 操作反馈及时，有 loading 状态 |
| 安全 | 敏感操作需二次确认 |
| 响应式 | 适配桌面和平板 |
