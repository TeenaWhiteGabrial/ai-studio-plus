# AI Coding 资源门户网站 - 产品需求规格说明书

## 1. 项目概述

### 1.1 项目定位
面向所有用户的资源发现与下载平台，提供 Skill、MCP、Plugin、文档、视频等资源的浏览、搜索、下载功能。

### 1.2 目标用户

| 角色 | 说明 | 权限 |
|------|------|------|
| 访客 | 未登录用户 | 仅浏览 |
| 一般用户 | 已注册但未认证 | 浏览、下载 |
| 控制台用户 | 通过团队认证 | 浏览、下载、上传、点赞、收藏、评论 |

### 1.3 核心目标
- 提供清晰的资源分类和便捷的搜索功能
- 支持资源的快速预览和下载
- 建立资源评价和互动机制
- 引导用户完成团队认证，进入控制台

## 3. 非功能性需求

| 类别 | 要求 |
|------|------|
| 性能 | 首屏加载 < 2s，列表分页 < 500ms |
| SEO | 支持搜索引擎优化，资源页面可被索引 |
| 响应式 | 适配桌面、平板、手机 |
| 安全 | HTTPS，防XSS，防CSRF |
| 可访问性 | 支持键盘操作，兼容屏幕阅读器 |
