## Context

**当前状态**：
- 登录页面无记住密码功能，用户每次访问需重新输入凭据
- 产出提交 API 无项目维度标识，无法按项目统计产出

**约束**：
- 前端：Vue 3 + Element Plus + Pinia
- 后端：Spring Boot + MyBatis
- 密码加密：已使用 JSEncrypt RSA 加密

**目标**：
- 记住密码功能采用 localStorage 存储
- 产出 API 新增字段需考虑向后兼容

## Goals / Non-Goals

**Goals:**
- 登录页添加"记住密码"复选框，用户可自主选择
- 记住的用户名和密码使用 localStorage 存储
- 产出提交 API 新增 `project_root_name` 参数
- 支持按项目统计产出数据

**Non-Goals:**
- 不涉及服务端会话管理变更
- 不修改现有产出数据结构（向后兼容）
- 不使用 Cookie 存储凭据

## Decisions

### 1. 记住密码存储方案
**决策**: 使用 localStorage 存储用户名和密码，密码使用 Base64 编码（非加密）

**理由**:
- 简单直接，与现有 token 存储方式一致
- 用户主动选择才存储，不强制
- 清除 localStorage 即可清除凭据

**替代方案考虑**:
- 使用加密存储：增加复杂度，本机使用场景安全性要求不高
- 使用 Cookie：与现有认证方式不一致

### 2. 项目根目录名参数设计
**决策**: `project_root_name` 作为可选参数，不强制要求

**理由**:
- 向后兼容，已有调用方无需修改
- 允许部分产出数据不带项目信息
- 未来可根据需要扩展项目维度统计

**替代方案考虑**:
- 必填参数：会破坏现有 API 兼容性
- 使用 projectId：需要额外维护项目映射表

## Risks / Trade-offs

**风险**: localStorage 存储密码安全性较低
- **缓解**: 明确提示用户仅在本机使用，清除浏览器数据可删除凭据

**风险**: 项目根目录名重复或格式不统一
- **缓解**: 前端提供标准化输入提示，后端可做简单校验

## Migration Plan

1. 前端：登录页添加记住密码复选框和用户存储逻辑
2. 后端：更新 OpenOutputSubmitRequest 添加 project_root_name 字段
3. 测试：验证记住密码登录和产出提交功能
