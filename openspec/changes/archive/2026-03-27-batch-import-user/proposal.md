## Why

当前用户管理功能仅支持逐个手动创建用户，当需要批量导入用户数据时操作效率低下。管理员需要从 Excel 或 CSV 文件导入用户数据时，必须逐条录入，费时费力且容易出错。本功能通过前端解析文件 + 后端批量接口的方式，实现高效、便捷的批量用户导入。

## What Changes

- 新增"批量导入"按钮，位于用户管理页面搜索栏
- 点击按钮弹出导入窗口，包含以下功能：
  - 下载导入模板（Excel 格式）
  - 上传 Excel (.xlsx, .xls) 或 CSV 文件
  - 前端解析文件并预览数据
  - 提交后端进行批量创建
  - 导入完成后显示成功/失败统计及明细
- 后端新增批量创建用户接口，支持一次创建多个用户
- 导入结果弹窗显示：成功数量、失败数量及每条失败数据的原因

## Capabilities

### New Capabilities

- `batch-user-import`: 批量导入用户功能，包括前端文件解析、数据校验、批量提交和结果展示

### Modified Capabilities

- `user-permission`: 新增批量创建用户接口，需要 SUPER_ADMIN 权限

## Impact

- **前端**:
  - 用户管理页面新增导入按钮和弹窗组件
  - 需要引入 Excel/CSV 解析库（如 xlsx）
  - 新增导入模板下载功能
  - 新增导入结果展示弹窗
- **后端**:
  - 新增批量创建用户接口 POST /api/user/batch
  - 返回导入结果（成功/失败明细）
- **数据库**: 无变更，复用现有用户表
