# 变更提案: Skill OSS 版本管理系统

## 背景

当前 Skill 系统基于 GitLab 集成，通过定时同步拉取技能文件。为了提供更灵活的技能管理能力，需要将架构改为 OSS 存储模式，并增加版本控制功能。

## 目标

将 Skill 管理从 GitLab 同步模式改造为 OSS 存储 + 版本控制模式，支持：
- 用户直接上传 ZIP 包创建/更新技能
- 自动版本号生成（支持大版本升级选择）
- 技能归属记录（创建者、部门）
- 多版本并存（仅超级管理员可查看历史版本）

## 范围

### 包含
- 数据库表结构调整
- 后端 API 开发
- 前端管理界面改造
- OSS 集成

### 不包含
- Claude Code 命令行集成
- 技能内容校验
- 审核流程
- 可见性控制（所有技能对所有人可见）

## 影响

- Skill 管理方式从拉取模式变为上传模式
- 需要迁移现有 GitLab 数据或重新上传

## 成功标准

- [ ] 用户可以创建技能并上传 ZIP 包
- [ ] 版本号自动生成，支持大版本选择
- [ ] 超级管理员可以查看和管理所有版本
- [ ] 普通用户只能看到最新版本
- [ ] 技能删除为软删除，保留历史版本
