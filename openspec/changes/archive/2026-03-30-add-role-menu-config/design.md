## Context

角色菜单当前硬编码在 SQL 初始化脚本中，需要支持超级管理员动态配置。

## Goals / Non-Goals

**Goals:**
- 超级管理员可配置 ADMIN 和 USER 角色的菜单
- 菜单树形展示，支持勾选
- 实时保存到数据库

**Non-Goals:**
- 不支持配置 SUPER_ADMIN 菜单（防止锁死）
- 不缓存菜单配置

## Decisions

### 决策 1: 可配置角色范围
**选择**: 仅允许配置 ADMIN 和 USER 角色

**理由**: SUPER_ADMIN 菜单固定拥有全部权限，防止误操作导致超级管理员无法访问系统

### 决策 2: 数据存储
**选择**: 直接操作 `sys_role_menu` 表，删除旧关联后插入新关联

**理由**: 简单直接，无需额外逻辑

### 决策 3: 接口设计
```
GET  /api/role/{id}/menus     - 获取菜单树（带 checked 标记）
PUT  /api/role/{id}/menus     - 更新菜单（传入 menuIds 数组）
```

### 决策 4: 前端交互
**选择**: 抽屉组件 + Tree 树形控件

**理由**: 直观展示层级，支持批量选择

## Risks / Trade-offs

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 配置错误导致角色无菜单 | 用户无法使用系统 | 保留基础菜单（如个人中心）不可取消 |
| 并发修改覆盖 | 低 | 简单场景暂不考虑乐观锁 |

## Migration Plan

无数据库变更，使用现有 `sys_role_menu` 表。
